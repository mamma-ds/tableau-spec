# Tableau仕様書生成ツール (tableau-spec)

Tableau の `.twb` / `.twbx` ファイルを解析し、HTML形式の仕様書を生成するツールです。
CLIでの一括生成と、Streamlitを使ったドラッグ＆ドロップ対応のWeb UIの両方を用意しています。

## 主な機能

- **概要・データソース**: ファイル情報、データソース一覧、接続種別、使用テーブル、カスタムSQL、テーブル結合（JOIN種別・結合条件）
- **フィールド一覧**: 各フィールドがどのシートで使われているかを表示
- **計算フィールド**: 計算式（常時表示）、LODバッジ、使用シート
- **パラメーター**: 名前・型・既定値
- **セット**: セット名・対象フィールド・定義（上位N件など）
- **未使用フィールド**: どのシート・計算式からも参照されていないフィールドの一覧（棚卸し用）
- **シート一覧／ダッシュボード一覧**: フィルター、使用フィールド、含まれるシート
- **依存関係ツリー**: シートを起点に、使用しているフィールド・計算フィールド（数式内の依存先を再帰的に展開）をツリー表示
  - 行・列・色・サイズ・ラベル・フィルター・ダッシュボードアクションなど「何に使われているか」を注記
  - 計算フィールドはマウスオーバーで数式を表示
  - シート／フィールド／計算フィールド／パラメータ名で検索・絞り込み
- **ダウンロードHTML単体でもタブ切り替え・検索が可能**（サーバー不要、素のJavaScriptで動作）

## 必要環境

- Python 3.9 以上
- Web UIを使う場合は `streamlit` が追加で必要です

## インストール

```bash
pip install -e .

# Web UIも使う場合
pip install -e ".[web]"
```

## 使い方

### CLI

```bash
tableau-spec sample.twb -o output.html --open
```

| オプション | 説明 |
|---|---|
| `input` | 入力する `.twb` または `.twbx` ファイル |
| `-o, --output` | 出力するHTMLファイルのパス（既定: `output.html`） |
| `--open` | 生成後にブラウザで開く |

### Web UI（Streamlit）

```bash
tableau-spec-web
```

ブラウザで `http://localhost:8501` が開き、`.twb` / `.twbx` ファイルをサイドバーにドラッグ＆ドロップすると仕様書が生成されます。生成されたHTMLはそのままダウンロードでき、ダウンロードしたファイル単体でもタブ切り替え・検索が利用できます。

## アーキテクチャ

責務分離のため5つのモジュールに分割しています。

| モジュール | ファイル | 責務 |
|---|---|---|
| パーサー | `tableau_spec/parser.py` | ファイルI/O・XML読み込みのみ |
| 解析 | `tableau_spec/analyzer.py` | XPath・データ抽出のみ |
| レポート | `tableau_spec/reporter.py` | HTML生成のみ |
| CLI | `tableau_spec/cli.py` | 引数処理・終了コードのみ |
| Web UI | `tableau_spec/webapp.py` | Streamlit UI・アップロードファイルの一時保存のみ |

詳細な開発ルールは [CLAUDE.md](CLAUDE.md) を参照してください。

## 開発

```bash
# テスト実行
python -m pytest tests/ -v

# カバレッジ確認
python -m pytest tests/ --cov=tableau_spec --cov-report=term-missing
```

`sample/` 配下に実際の `.twbx` ファイルを配置すると、それを使った結合テスト（`tests/test_integration.py`）も実行されます。サンプルファイルは実データを含むためリポジトリには含めていません。各自 `.twb` / `.twbx` ファイルを `sample/` に置いてください（未配置の場合、結合テストはスキップされます）。

## 現在の既知の制限

- Tableau XMLの名前空間（`twb:`）がある場合は未対応
- カスタムSQL抽出は `relation type="text"` のみ対応
- テーブル結合は2テーブルのpairwise joinを前提に表示（3テーブル以上のネストした結合は内訳までは展開しない）
- セットの定義説明は簡略化しており、大まかな分類（上位N件・メンバー指定など）のみ
- ダウンロードしたHTML単体の検索はクライアントサイドJSによる簡易実装で、行の表示/非表示のみ（Streamlit版のようなハイライト表示はしない）
