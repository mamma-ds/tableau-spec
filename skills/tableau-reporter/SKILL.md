# Tableau Reporter スキル

## 責務
- WorkbookSpec → HTML 文字列の変換のみ
- ファイル書き込みなし（呼び出し元の cli.py が行う）
- XPath・XML処理なし

## デザイン規約
- ダークテーマ（背景 #0f172a）
- CSS変数で色管理（var(--accent) など）
- テーブルはボーダー付き、偶数行は薄く色付け
- LODフィールドには .badge-lod クラスでオレンジバッジ
- カスタムSQLは <details><summary> で折りたたみ
- 計算フィールドの数式は <details open> でデフォルト展開表示にする（折りたたまない）
- シート名・ダッシュボード名の先頭に `.color-swatch` クラスの小さな色付き矩形を表示する
  (Sheet.color / Dashboard.color が `#rrggbb` 形式のときのみ。それ以外は何も表示しない)

## セクション構成
1. 概要（ファイル名・生成日時・各要素数）
2. データソース（接続情報・テーブル・カスタムSQL）
3. 計算フィールド（列順は フィールド名 → 計算式 → データソース。LODバッジ付き・数式は常時展開）
4. パラメーター
5. シート一覧（タブ色・フィルター・使用フィールド・使用計算フィールドを含む）
6. ダッシュボード一覧（タブ色・含まれるシートを含む）

## テスト方針
- WorkbookSpec を直接インスタンス化して渡す（ファイル不要）
- html.escape が適用されていること（XSS対策）を必ずテスト
- color に不正な値（CSS injection を狙った文字列など）が来た場合、
  `#rrggbb` 形式の検証で弾かれ style 属性に出力されないことをテスト
